# ModuNest Studio

Konfiguratoren für 3D-Druck-Produkte von **Art vom Hof** (installierbar als App).

- App: https://mikesch15.github.io/ModuNest-Studio/ (Produktauswahl → z. B. `modunest/`)
- Admin: https://mikesch15.github.io/ModuNest-Studio/admin/ (nur mit Admin-Schlüssel nutzbar)
- Quellcode: `quellcode/` (Bauen: `cd quellcode && python3 assemble.py`)
- Details und Aufbau für weitere Produkte: `CLAUDE.md`
