    Bestellungen

    Etsy = Bestellung (kommt automatisch nach der Zahlung), Code = von dir erstellter Code. Darunter die gekauften Artikel (grau = kein Konfigurator-Angebot). Gelb «prüfen»: Etsy hat nicht mitgeteilt, was gekauft wurde, oder es waren noch keine Angebote eingetragen – schau die Bestellung in Etsy an und gib sie mit Produkt und Anzahl frei. Details öffnet alles zur Bestellung: Guthaben und Verbrauch pro Produkt ändern, Notiz, Status (gesperrt = kann nichts mehr herunterladen), Downloads der letzten 2 Tage, löschen.

    Noch nicht verbunden.

    Produkte

    Live = für alle sichtbar. Test = nur auf deinen Geräten mit gespeichertem Admin-Schlüssel sichtbar; Kunden sehen «Bald verfügbar». Herunterladen geht im Test nur mit deinen Codes. Aus = für alle gesperrt. Bei den Optionen kannst du einzelne Teile eines Konfigurators abschalten (z. B. noch nicht fertig getestet) – sie verschwinden dann aus der App. Änderungen gelten beim nächsten Öffnen der App.

    Konfigurator-Angebote

    Nur diese Etsy-Angebote geben Guthaben. Pro Angebot: für welches Produkt und wie viele Einheiten ein Stück enthält (ModuNest: Kisten, Namenspuzzle: 1 = ein Puzzle). Das Guthaben gilt nur für dieses Produkt. Kauft jemand 2 Stück, gibt es doppelt so viel; andere Artikel derselben Bestellung zählen nicht. Die Angebotsnummer steht in der Adresse deines Angebots: etsy.com/listing/1234567890/…. «Pausieren» lässt ein altes Angebot nichts mehr geben, ohne es zu löschen. Änderungen gelten für neue Bestellungen.

    Noch keine Angebote eingetragen. Bis dahin landen alle Etsy-Bestellungen unter «prüfen».

    Code erstellen

    Für Sonderfälle: Geschenk, Ersatz, Test oder wenn die Etsy-Nummer nicht funktioniert. Der Code funktioniert im Konfigurator wie eine Etsy-Bestellnummer, aber nur für das gewählte Produkt. Mit Codes kannst du auch Produkte im Status «Test» herunterladen. Schreib in die Notiz, für wen der Code ist. Mehr Guthaben oder ein weiteres Produkt gibst du später unter Bestellungen → Details.

    Etsy-Bestellung eintragen

    Wenn ein Käufer meldet, dass seine Bestellnummer nicht geht: Nummer in Etsy prüfen (Shop-Manager → Bestellungen) und hier mit Produkt und Anzahl eintragen. Gibt es die Bestellung schon, wird das Guthaben für dieses Produkt auf den neuen Wert gesetzt (andere Produkte bleiben). Bereits Verbrauchtes bleibt verbraucht.

    Etsy-Verbindung

    Etsy meldet bei einer Bestellung nur die Bestellnummer. Damit der Server nachschauen kann, was gekauft wurde, braucht er einmalig deine Erlaubnis (nur Lesen von Bestellungen). Ohne Verbindung landen alle Bestellungen unter «prüfen». Die Verbindung erneuert sich jedes Mal, wenn du den Admin öffnest; nach 90 Tagen ohne Öffnen musst du neu verbinden.

    –
    Verbindung testen (ohne Kauf)

    Gib die Nummer einer beliebigen alten Bestellung aus deinem Shop ein (Shop-Manager → Bestellungen). Der Server fragt Etsy, was darin gekauft wurde, und zeigt, was das geben würde. Es wird nichts gespeichert.
