ModuNest Admin

Nur für dich: Codes erstellen und Bestellungen verwalten

So geht’s

  1. Admin-Schlüssel eingeben und Verbinden tippen.
  2. In der Übersicht siehst du alle Bestellungen und wie viele Kisten verbraucht sind.
  3. Unter Konfigurator-Angebote trägst du einmal deine Etsy-Angebote ein, die zum Konfigurator gehören, mit Kisten pro Stück.
  4. Gelb markierte Bestellungen (prüfen) gibst du mit der richtigen Kistenzahl frei.
  5. Hat ein Käufer ein Problem, trägst du seine Etsy-Bestellnummer ein oder schenkst ihm einen Code.

Etsy-Bestellungen kommen nach der Zahlung automatisch hierher. Gezählt werden nur deine Konfigurator-Angebote, andere Shop-Artikel nicht. Normalerweise musst du nichts tun. Das ⓘ bei jedem Abschnitt erklärt mehr.

Verbindung

Den Admin-Schlüssel hast du selbst in Supabase als Secret ADMIN_KEY gespeichert (Edge Functions → Secrets). Er wird nur an deinen Server geschickt. «Merken» speichert ihn im Browser dieses Geräts – nur auf deinem eigenen Handy/Computer benutzen. Die Server-Adresse musst du normalerweise nicht ändern.

Übersicht

Etsy = Bestellung (kommt automatisch nach der Zahlung), Code = von dir erstellter Code. Darunter stehen die gekauften Artikel (grau = kein Konfigurator-Angebot, gibt 0 Kisten). Der Balken zeigt, wie viele Kisten schon heruntergeladen wurden. Gelb «prüfen»: Etsy hat nicht mitgeteilt, was gekauft wurde, oder es waren noch keine Angebote eingetragen. Schau die Bestellung in Etsy an (Shop-Manager → Bestellungen) und gib sie mit der richtigen Kistenzahl frei – vorher kann der Käufer nichts herunterladen. Fehlt eine bezahlte Bestellung, war Etsy evtl. langsam (ein paar Minuten warten) – sonst unten von Hand eintragen.

Etsy-Verbindung

Etsy meldet bei einer Bestellung nur die Bestellnummer. Damit der Server nachschauen kann, was gekauft wurde, braucht er einmalig deine Erlaubnis (nur Lesen von Bestellungen). Ohne Verbindung landen alle Bestellungen unter «prüfen». Die Verbindung erneuert sich jedes Mal, wenn du den Admin öffnest; nach 90 Tagen ohne Öffnen musst du neu verbinden.

Konfigurator-Angebote

Nur diese Etsy-Angebote geben Kisten. Pro Angebot: wie viele Kisten ein Stück enthält und für welches Produkt es ist. Kauft jemand 2 Stück, gibt es doppelt so viele Kisten; andere Artikel derselben Bestellung zählen nicht. Die Angebotsnummer steht in der Adresse deines Angebots: etsy.com/listing/1234567890/… (oder Shop-Manager → Angebote → Angebot öffnen). «Pausieren» lässt ein altes Angebot keine Kisten mehr geben, ohne es zu löschen. Änderungen gelten für neue Bestellungen.

Noch keine Angebote eingetragen. Bis dahin landen alle Etsy-Bestellungen unter «prüfen».

Code erstellen

Für Sonderfälle: Geschenk, Ersatz, Test oder wenn die Etsy-Nummer nicht funktioniert. Der Code funktioniert im Konfigurator genau wie eine Etsy-Bestellnummer. Jede Kiste (Modul) braucht 1. Schreib in die Notiz, für wen der Code ist.

Etsy-Bestellung eintragen

Wenn ein Käufer meldet, dass seine Bestellnummer nicht geht: Nummer in Etsy prüfen (Shop-Manager → Bestellungen) und hier eintragen. Ist die Nummer schon vorhanden, wird die Gesamtzahl Kisten auf den neuen Wert gesetzt – so kannst du Kisten nachschenken. Bereits verbrauchte Kisten bleiben verbraucht.
